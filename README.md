# Portfolio

Welcome to my data science and machine learning portfolio. Below you will find a brief description of each project included in this repository.

## Projects

### 1. In-hospital_morality_prediction
A machine learning project focused on predicting in-hospital mortality rates using patient clinical data.

### 2. PL_best_scorer
A data analysis and modeling project aimed at predicting and identifying the top goal scorers in the English Premier League.

### 3. Predicting_Vehicle_Prices
A regression model built to accurately predict the market prices of used vehicles based on their various features and specifications.

### 4. Predicting_over_2.5_Goals_PL
A predictive model designed to forecast whether an English Premier League football match will end with over 2.5 goals scored.

### 5. fpl-points-predictor
A predictive tool created to forecast future points for players in the Fantasy Premier League (FPL), helping managers make better transfer decisions.
